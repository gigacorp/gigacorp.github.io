Fluffy Fonts

A soft keyboard for iPhone that types in cute font styles in any app. No ads, no in-app purchases, no tracking.

Turn on the keyboard

Open Settings → General → Keyboard → Keyboards → Add New Keyboard, and choose Fluffy Fonts. In any text field, hold or tap the globe key to switch to it.

Do I need Full Access?

No. Every style works without it. Full Access lets the keyboard use the theme, photo and favorite styles you set in the app, and haptic feedback. Either way, nothing you type leaves your iPhone.

Why do some letters stay plain?

Each style uses special Unicode characters, and a few letters have no match in some styles. For example, there is no tiny "q". The app shows which letters each style covers.

Why is the keyboard gone in a password field?

iOS always uses its own keyboard for passwords and some number fields. That is a protection built into iOS.
